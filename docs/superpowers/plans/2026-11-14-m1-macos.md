# M1 macOS 版实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 macOS 原生 arm64 托盘应用 FastGithub GUI，一键开关 GitHub 加速（内核 x64 经 Rosetta），含 root 守护进程、防断网、git 加速，并产出 `.dmg`。

**Architecture:** Tauri 2 托盘应用（普通用户）+ 同 crate 第二个二进制 `fastgithub-gui-helper`（root LaunchDaemon）。GUI 与 daemon 保持一条 unix socket 长连接，断开即自动还原代理。共享核心（状态机/路径/git/内核/协议）与 macOS 后端（代理/证书/守护/安装）分模块。

**Tech Stack:** Rust（stable）、Tauri 2（tray-icon, image-png）、serde/serde_json、anyhow、libc；Node + @tauri-apps/cli 仅用于打包；Python3 stdlib 生成图标。

**Spec:** `docs/superpowers/specs/2026-11-14-fastgithub-gui-design.md`

## Global Constraints

- 上游内核固定版本 **v2.1.5**，来源 `https://github.com/creazyboyone/FastGithub/releases/download/v2.1.5/`，**仅官方源，禁止镜像**。
- macOS 内核只有 `fastgithub-osx-x64.tar.gz`（无 arm64）；应用本体 arm64 原生，内核经 Rosetta 运行。
- 下载一律 `curl --http1.1`（本机 HTTP/2 经代理会失败，退出码 16）。
- 官方未公布 SHA256：固定版本 + 固定哈希。**osx-x64 v2.1.5 已验证哈希 = `16dca5cecedf1d67eca45ca01069ccfb35b3214eecd74033829fd23074b31fdc`**（2026-11-14 从官方源 HTTP/1.1 下载计算，与用户已有包一致）。
- 代理地址固定 `127.0.0.1:38457`。
- git 仅配置 `http.https://github.com.proxy` 与 `http.https://github.com.sslCAInfo`，**绝不修改 http.sslVerify**。
- 许可证：保留上游 FastGithub MIT（Copyright (c) 2021 老九）与 dnscrypt-proxy ISC 全文；释放内核时一并保留其原始 LICENSE。
- 任何 enable 步骤失败必须回滚，不残留半开状态；应用退出/崩溃必须还原系统代理。
- 所有系统命令用 `std::process::Command`，错误用 `anyhow::Result` 传播。
- 提交信息用 conventional commits（feat/fix/test/docs/chore）。

## 架构修正（真机验证后，覆盖 Task 8/9 中相关代码块）

真机暴露：root LaunchDaemon 内启动内核会触发 .NET AppleCrypto `CreateSelfSigned`/`CopyWithPrivateKey` 报 “keychain item no longer valid”——root 守护进程没有用户 GUI/keychain 会话。据此修正职责划分：

- **内核改由 GUI app（用户会话）作为子进程启动**：`backend::macos::MacBackend::enable` 先 `kernel::spawn` 并记录 `kernel_pid`，`kernel::wait_port(PROXY_PORT, 20)` 等待监听；失败时把 `logs/fastgithub.log` 尾部 6 行并入报错便于诊断。任何失败/关闭/卸载都 `stop_kernel()` 杀掉该 pid。
- **root daemon 只负责系统代理 + 证书信任**，不再 spawn/kill 内核：`daemon::enable` = 信任证书 + 备份并设置代理；`disable` = 还原代理 + `kill_kernel`（`pkill -f "{kernel_dir}/fastgithub"` 兜底清理残留）；`DaemonState` 去掉 `kernel_pid`，新增 `kernel_dir`。
- **连接重试**：`ensure_conn` 在 8s 内每 200ms 重试 connect，规避 daemon 重启时 socket 绑定竞态（ENOENT）。
- **helper 自动刷新**：`install::helper_current(resource_helper)` 逐字节比对已安装 helper 与打包内 helper；`main.rs` 开启时若 `!components_installed() || !helper_current(...)` 则重装（升级 app 后一次性授权刷新 daemon，避免新旧混跑）。`install_components` 先清空缓存连接。
- **证书 CN 解析**：`cert::cert_cn` 依次尝试 `openssl x509 -inform PEM` 再 `DER`（上游 `.cer` 实为 PEM）；`parse_cn` 先剥离 `subject=` 前缀再取 CN。
- **内核改为源码编译（覆盖 Task 2 的下载二进制路线）**：官方 v2.1.5 内置 .NET 7，在 macOS 15+ 因 AppleCrypto bug 必崩且 .NET 7 永不修复（修复仅在 6.0.34/8.0.10/9.0）。经用户批准，三平台统一从官方源码（creazyboyone/FastGithub tag v2.1.5 = commit `20ef81111fecc9ebed68a1166aaeb815cdcec8c1`，MIT）retarget 到 .NET 8 编译。`scripts/build-kernel.sh` 取代 `fetch-kernel.sh`：下载源码 tarball（仅官方 codeload）+ 固定 SHA256 + 校验 tag→commit + sed retarget（net7→net8、Hosting 7.0-rc→8.0.0）+ `dotnet publish -p:InformationalVersion=2.1.5+source`（`ProductionVersion.Parse` 需含 `+`）+ chmod dnscrypt-proxy。实测 macOS 26.5 生成证书、监听 38457、MITM 代理 github.com 返回 200。Yarp 1.1.1 有 NU1903 高危漏洞，M4 加固处理。
- **内核升级重释放**：`main.rs` 启动时由「仅缺失才释放」改为 `kernel::needs_extract`（sha2 比对 bundled 与已释放主二进制哈希，不一致即 `extract_resources` 覆盖），确保 app 升级内核后用户目录同步刷新。新增依赖 `sha2 = "0.10"`。

```rust
use tauri::{menu::{Menu, MenuItem}, tray::TrayIconBuilder, Manager};

fn main() -> anyhow::Result<()> {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(target_os = "macos")]
            app.set_activation_policy(tauri::ActivationPolicy::Accessory);
            let quit = MenuItem::with_id(app, "quit", "退出", true, None::<&str>)?;
            let menu = Menu::with_items(app, &[&quit])?;
            TrayIconBuilder::with_id("main")
                .icon(app.default_window_icon().unwrap().clone())
                .menu(&menu)
                .show_menu_on_left_click(true)
                .on_menu_event(|app, e| {
                    if e.id.as_ref() == "quit" { app.exit(0); }
                })
                .build(app)?;
            Ok(())
        })
        .build(tauri::generate_context!())?
        .run(|_app, event| {
            if let tauri::RunEvent::ExitRequested { api, code, .. } = event {
                if code.is_none() { api.prevent_exit(); }
            }
        });
    Ok(())
}
```

```python
import struct, zlib, os

def write_png(path, w, h, rgba):
    def chunk(t, d):
        c = t + d
        return struct.pack(">I", len(d)) + c + struct.pack(">I", zlib.crc32(c) & 0xffffffff)
    raw = b"".join(b"\x00" + bytes(rgba[y*w*4:(y+1)*w*4]) for y in range(h))
    out = b"\x89PNG\r\n\x1a\n"
    out += chunk(b"IHDR", struct.pack(">IIBBBBB", w, h, 8, 6, 0, 0, 0))
    out += chunk(b"IDAT", zlib.compress(raw, 9))
    out += chunk(b"IEND", b"")
    os.makedirs(os.path.dirname(path), exist_ok=True)
    open(path, "wb").write(out)

def circle(size, color):
    w = h = size
    r = size * 0.42
    cx = cy = size / 2
    px = bytearray(w * h * 4)
    for y in range(h):
        for x in range(w):
            if (x - cx) ** 2 + (y - cy) ** 2 <= r * r:
                i = (y * w + x) * 4
                px[i:i+4] = bytes(color) + b"\xff"
    return px

write_png("assets/app-icon.png", 1024, 1024, circle(1024, (79, 70, 229)))
write_png("src-tauri/icons/tray-on.png", 32, 32, circle(32, (34, 197, 94)))
write_png("src-tauri/icons/tray-off.png", 32, 32, circle(32, (156, 163, 175)))
print("icons written")
```

- [ ] **Step 1: 写 `scripts/fetch-kernel.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail
VERSION="v2.1.5"
BASE="https://github.com/creazyboyone/FastGithub/releases/download/${VERSION}"
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
DEST="$ROOT/src-tauri/resources/kernel"
ASSET="fastgithub-osx-x64.tar.gz"
HASH_FILE="$ROOT/scripts/kernel-sha256-osx-x64.txt"
CACHE="$ROOT/.cache"
mkdir -p "$CACHE" "$DEST"

TARBALL="$CACHE/$ASSET"
if [ ! -f "$TARBALL" ]; then
  echo "下载官方内核 $ASSET ..."
  curl -sSL --http1.1 --retry 3 --max-time 600 -o "$TARBALL" "$BASE/$ASSET"
fi

ACTUAL="$(shasum -a 256 "$TARBALL" | awk '{print $1}')"
if [ -f "$HASH_FILE" ]; then
  EXPECTED="$(cat "$HASH_FILE")"
  if [ "$ACTUAL" != "$EXPECTED" ]; then
    echo "SHA256 不匹配！期望 $EXPECTED 实际 $ACTUAL" >&2
    exit 1
  fi
  echo "SHA256 校验通过"
else
  echo "$ACTUAL" > "$HASH_FILE"
  echo "首次下载，已固定哈希到 $HASH_FILE"
fi

tar -xzf "$TARBALL" -C "$DEST"
chmod +x "$DEST/fastgithub" "$DEST/dnscrypt-proxy/dnscrypt-proxy" 2>/dev/null || true
echo "内核已释放到 $DEST"
ls "$DEST"
```

```rust
    if out.status.success() { Some(String::from_utf8_lossy(&out.stdout).trim().to_string()) } else { None }

    Command::new("git").args(args).status().context("运行 git 失败")?;
```

```rust
use anyhow::{Context, Result, bail};
use std::process::Command;
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ProxySetting { pub enabled: bool, pub server: String, pub port: u16 }

pub fn parse_getwebproxy(output: &str) -> ProxySetting {
    let mut enabled = false; let mut server = String::new(); let mut port = 0u16;
    for line in output.lines() {
        let line = line.trim();
        if let Some(v) = line.strip_prefix("Enabled:") { enabled = v.trim().eq_ignore_ascii_case("yes"); }
        else if let Some(v) = line.strip_prefix("Server:") { server = v.trim().to_string(); }
        else if let Some(v) = line.strip_prefix("Port:") { port = v.trim().parse().unwrap_or(0); }
    }
    ProxySetting { enabled, server, port }
}

pub fn parse_default_interface(route_output: &str) -> Option<String> {
    for line in route_output.lines() {
        if let Some(v) = line.trim().strip_prefix("interface:") { return Some(v.trim().to_string()); }
    }
    None
}

pub fn parse_service_order(output: &str) -> Vec<(String, String)> {
    let mut result = Vec::new();
    let mut pending: Option<String> = None;
    for line in output.lines() {
        let line = line.trim();
        if line.starts_with('(') && !line.starts_with("(Hardware") {
            if let Some(idx) = line.find(')') {
                let name = line[idx+1..].trim().to_string();
                if !name.is_empty() { pending = Some(name); }
            }
        } else if line.starts_with("(Hardware Port:") {
            if let Some(dev_idx) = line.find("Device:") {
                let dev = line[dev_idx+7..].trim().trim_end_matches(')').trim().to_string();
                if let Some(name) = pending.take() { result.push((name, dev)); }
            }
        }
    }
    result
}

pub fn service_for_interface(services: &[(String, String)], iface: &str) -> Option<String> {
    services.iter().find(|(_, d)| d == iface).map(|(n, _)| n.clone())
}

fn run(cmd: &str, args: &[&str]) -> Result<String> {
    let out = Command::new(cmd).args(args).output().with_context(|| format!("运行 {cmd} 失败"))?;
    if !out.status.success() { bail!("{cmd} 失败: {}", String::from_utf8_lossy(&out.stderr)); }
    Ok(String::from_utf8_lossy(&out.stdout).to_string())
}

pub fn default_service() -> Result<String> {
    let route = run("route", &["-n", "get", "default"])?;
    let iface = parse_default_interface(&route).context("无法解析默认网卡")?;
    let order = run("networksetup", &["-listnetworkserviceorder"])?;
    service_for_interface(&parse_service_order(&order), &iface).context("无法映射网络服务")
}

pub fn get_proxy(service: &str) -> Result<(ProxySetting, ProxySetting)> {
    let web = parse_getwebproxy(&run("networksetup", &["-getwebproxy", service])?);
    let secure = parse_getwebproxy(&run("networksetup", &["-getsecurewebproxy", service])?);
    Ok((web, secure))
}

pub fn set_proxy(service: &str, host: &str, port: u16) -> Result<()> {
    let p = port.to_string();
    run("networksetup", &["-setwebproxy", service, host, &p])?;
    run("networksetup", &["-setsecurewebproxy", service, host, &p])?;
    run("networksetup", &["-setwebproxystate", service, "on"])?;
    run("networksetup", &["-setsecurewebproxystate", service, "on"])?;
    Ok(())
}

pub fn restore_proxy(service: &str, web: &ProxySetting, secure: &ProxySetting) -> Result<()> {
    if !web.server.is_empty() { run("networksetup", &["-setwebproxy", service, &web.server, &web.port.to_string()])?; }
    run("networksetup", &["-setwebproxystate", service, if web.enabled {"on"} else {"off"}])?;
    if !secure.server.is_empty() { run("networksetup", &["-setsecurewebproxy", service, &secure.server, &secure.port.to_string()])?; }
    run("networksetup", &["-setsecurewebproxystate", service, if secure.enabled {"on"} else {"off"}])?;
    Ok(())
}
```

```rust
use anyhow::{Context, Result, bail};
use std::path::Path;
use std::process::Command;

pub fn parse_cn(subject: &str) -> Option<String> {
    let subject = subject.trim().strip_prefix("subject=").unwrap_or(subject.trim());
    for part in subject.split(|c| c == ',' || c == '/') {
        let part = part.trim();
        if let Some(v) = part.strip_prefix("CN") {
            let v = v.trim_start_matches(|c| c == '=' || c == ' ').trim();
            if !v.is_empty() { return Some(v.to_string()); }
        }
    }
    None
}

pub fn cert_cn(cer: &Path) -> Result<String> {
    let out = Command::new("openssl")
        .args(["x509", "-inform", "DER", "-in"]).arg(cer)
        .args(["-noout", "-subject"]).output().context("运行 openssl 失败")?;
    if !out.status.success() { bail!("读取证书主题失败"); }
    parse_cn(&String::from_utf8_lossy(&out.stdout)).context("证书无 CN")
}

const KEYCHAIN: &str = "/Library/Keychains/System.keychain";

pub fn is_trusted(cn: &str) -> bool {
    Command::new("security").args(["find-certificate", "-c", cn, KEYCHAIN])
        .output().map(|o| o.status.success()).unwrap_or(false)
}

pub fn install_trusted(cer: &Path) -> Result<()> {
    let out = Command::new("security")
        .args(["add-trusted-cert", "-d", "-r", "trustRoot", "-k", KEYCHAIN]).arg(cer)
        .output().context("安装证书失败")?;
    if !out.status.success() { bail!("信任证书失败: {}", String::from_utf8_lossy(&out.stderr)); }
    Ok(())
}

pub fn remove_trusted(cn: &str) -> Result<()> {
    let _ = Command::new("security").args(["delete-certificate", "-c", cn, "-t", KEYCHAIN]).output();
    Ok(())
}
```

```rust
use anyhow::{Context, Result, bail};
use std::net::TcpStream;
use std::path::Path;
use std::process::{Command, Stdio};
use std::time::{Duration, Instant};

pub fn spawn(kernel_dir: &Path) -> Result<u32> {
    let bin = kernel_dir.join("fastgithub");
    let log = kernel_dir.parent().unwrap().join("logs").join("fastgithub.log");
    if let Some(p) = log.parent() { std::fs::create_dir_all(p)?; }
    let logf = std::fs::File::create(&log).context("创建日志文件失败")?;
    let child = Command::new(&bin)
        .current_dir(kernel_dir)
        .stdout(Stdio::from(logf.try_clone()?))
        .stderr(Stdio::from(logf))
        .spawn().with_context(|| format!("启动内核失败: {}", bin.display()))?;
    Ok(child.id())
}

pub fn wait_port(port: u16, secs: u64) -> Result<()> {
    let deadline = Instant::now() + Duration::from_secs(secs);
    while Instant::now() < deadline {
        if TcpStream::connect(("127.0.0.1", port)).is_ok() { return Ok(()); }
        std::thread::sleep(Duration::from_millis(300));
    }
    bail!("内核未在 {secs}s 内监听端口 {port}")
}

pub fn kill(pid: u32) {
    unsafe { libc::kill(pid as i32, libc::SIGTERM); }
    std::thread::sleep(Duration::from_millis(500));
    unsafe { libc::kill(pid as i32, libc::SIGKILL); }
}

pub fn extract_resources(resource_kernel: &Path, dest: &Path) -> Result<()> {
    copy_dir(resource_kernel, dest)
}

fn copy_dir(src: &Path, dst: &Path) -> Result<()> {
    std::fs::create_dir_all(dst)?;
    for entry in std::fs::read_dir(src)? {
        let entry = entry?;
        let to = dst.join(entry.file_name());
        if entry.file_type()?.is_dir() { copy_dir(&entry.path(), &to)?; }
        else { std::fs::copy(entry.path(), &to)?; }
    }
    Ok(())
}
```

```rust
use crate::protocol::{Request, Response};
use crate::macos::{proxy, cert};
use crate::kernel;
use anyhow::{Context, Result, bail};
use serde::{Deserialize, Serialize};
use std::io::{BufRead, BufReader, Write};
use std::os::unix::net::{UnixListener, UnixStream};
use std::path::{Path, PathBuf};

pub const SOCKET_PATH: &str = "/var/run/fastgithub-gui.sock";
pub const STATE_FILE: &str = "/Library/Application Support/FastGithubGUI/daemon-state.json";
pub const PROXY_HOST: &str = "127.0.0.1";
pub const PROXY_PORT: u16 = 38457;

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct DaemonState {
    pub installer_uid: u32,
    pub service: String,
    pub web_backup: Option<proxy::ProxySetting>,
    pub secure_backup: Option<proxy::ProxySetting>,
    pub proxy_set_by_us: bool,
    pub kernel_pid: Option<u32>,
    pub kernel_dir: String,
}

impl DaemonState {
    pub fn load() -> DaemonState {
        std::fs::read_to_string(STATE_FILE).ok()
            .and_then(|s| serde_json::from_str(&s).ok()).unwrap_or_default()
    }
    pub fn save(&self) -> Result<()> {
        if let Some(p) = Path::new(STATE_FILE).parent() { std::fs::create_dir_all(p)?; }
        std::fs::write(STATE_FILE, serde_json::to_vec_pretty(self)?)?;
        Ok(())
    }
}

fn enable(state: &mut DaemonState, kernel_dir: &str) -> Result<()> {
    let kdir = PathBuf::from(kernel_dir);
    state.kernel_dir = kernel_dir.into();
    let pid = kernel::spawn(&kdir)?;
    state.kernel_pid = Some(pid);
    state.save()?;
    kernel::wait_port(PROXY_PORT, 15)?;
    let cer = kdir.join("cacert").join("fastgithub.cer");
    let cn = cert::cert_cn(&cer)?;
    if !cert::is_trusted(&cn) { cert::install_trusted(&cer)?; }
    let service = proxy::default_service()?;
    let (web, secure) = proxy::get_proxy(&service)?;
    state.service = service.clone();
    state.web_backup = Some(web);
    state.secure_backup = Some(secure);
    proxy::set_proxy(&service, PROXY_HOST, PROXY_PORT)?;
    state.proxy_set_by_us = true;
    state.save()?;
    Ok(())
}

fn disable(state: &mut DaemonState) -> Result<()> {
    if state.proxy_set_by_us {
        if let (Some(w), Some(s)) = (&state.web_backup, &state.secure_backup) {
            let _ = proxy::restore_proxy(&state.service, w, s);
        }
        state.proxy_set_by_us = false;
    }
    if let Some(pid) = state.kernel_pid.take() { kernel::kill(pid); }
    state.save()?;
    Ok(())
}

fn uninstall_cleanup(state: &mut DaemonState) {
    let _ = disable(state);
    let cer = PathBuf::from(&state.kernel_dir).join("cacert").join("fastgithub.cer");
    if let Ok(cn) = cert::cert_cn(&cer) { let _ = cert::remove_trusted(&cn); }
}

fn cleanup(state: &mut DaemonState) {
    if state.proxy_set_by_us {
        if let (Some(w), Some(s)) = (&state.web_backup, &state.secure_backup) {
            let _ = proxy::restore_proxy(&state.service, w, s);
        }
        state.proxy_set_by_us = false;
    }
    if let Some(pid) = state.kernel_pid.take() { kernel::kill(pid); }
    let _ = state.save();
}

fn peer_uid(stream: &UnixStream) -> Result<u32> {
    use std::os::unix::io::AsRawFd;
    let mut uid: libc::uid_t = 0; let mut gid: libc::gid_t = 0;
    if unsafe { libc::getpeereid(stream.as_raw_fd(), &mut uid, &mut gid) } != 0 { bail!("getpeereid 失败"); }
    Ok(uid)
}

fn handle_connection(stream: UnixStream, state: &mut DaemonState) {
    let mut writer = stream.try_clone().expect("clone stream");
    let reader = BufReader::new(stream);
    for line in reader.lines() {
        let line = match line { Ok(l) => l, Err(_) => break };
        let req: Request = match serde_json::from_str(&line) { Ok(r) => r, Err(_) => continue };
        let resp = match req {
            Request::Enable { kernel_dir } => match enable(state, &kernel_dir) {
                Ok(_) => Response::ok("on"),
                Err(e) => { let _ = disable(state); Response::err("off", format!("{e:#}")) }
            },
            Request::Disable => match disable(state) { Ok(_) => Response::ok("off"), Err(e) => Response::err("off", format!("{e:#}")) },
            Request::Status => Response::ok(if state.proxy_set_by_us {"on"} else {"off"}),
            Request::Uninstall => { uninstall_cleanup(state); Response::ok("off") }
        };
        let _ = writeln!(writer, "{}", serde_json::to_string(&resp).unwrap());
        let _ = writer.flush();
    }
}

pub fn run() -> Result<()> {
    let mut state = DaemonState::load();
    cleanup(&mut state);
    let _ = std::fs::remove_file(SOCKET_PATH);
    let listener = UnixListener::bind(SOCKET_PATH).context("绑定 socket 失败")?;
    {
        use std::os::unix::fs::PermissionsExt;
        std::fs::set_permissions(SOCKET_PATH, std::fs::Permissions::from_mode(0o666))?;
    }
    for stream in listener.incoming() {
        let stream = stream?;
        let uid = peer_uid(&stream)?;
        if state.installer_uid == 0 { state.installer_uid = uid; state.save()?; }
        else if uid != state.installer_uid { continue; }
        handle_connection(stream, &mut state);
        let _ = disable(&mut state);
    }
    Ok(())
}
```

```rust
fn apple_quote(s: &str) -> String {
    format!("\"{}\"", s.replace('\\', "\\\\").replace('"', "\\\""))
}

fn osascript_admin(cmd: &str) -> Result<()> {
    let script = format!("do shell script {} with administrator privileges", apple_quote(cmd));
    let out = Command::new("osascript").arg("-e").arg(script).output().context("运行 osascript 失败")?;
    if !out.status.success() {
        let err = String::from_utf8_lossy(&out.stderr);
        if err.contains("-128") { bail!("用户取消了授权"); }
        bail!("授权操作失败: {err}");
    }
    Ok(())
}

fn run_temp_script(script: &str) -> Result<()> {
    let tmp = std::env::temp_dir().join(format!("fastgithub-script-{}.sh", std::process::id()));
    std::fs::write(&tmp, script)?;
    let cmd = format!("/bin/sh '{}'", tmp.display());
    let r = osascript_admin(&cmd);
    let _ = std::fs::remove_file(&tmp);
    r
}
```

```rust
use crate::backend::PlatformBackend;
use crate::protocol::{Request, Response};
use crate::macos::{install, daemon};
use crate::{gitcfg, paths};
use anyhow::{Context, Result, bail};
use std::io::{BufRead, BufReader, Write};
use std::os::unix::net::UnixStream;
use std::path::Path;
use std::sync::Mutex;

struct Conn { writer: UnixStream, reader: BufReader<UnixStream> }

pub struct MacBackend { conn: Mutex<Option<Conn>> }

impl MacBackend {
    pub fn new() -> Self { MacBackend { conn: Mutex::new(None) } }

    fn ensure_conn(&self) -> Result<()> {
        let mut g = self.conn.lock().unwrap();
        if g.is_some() { return Ok(()); }
        let stream = UnixStream::connect(daemon::SOCKET_PATH).context("连接后台守护进程失败（组件未安装？）")?;
        let reader = BufReader::new(stream.try_clone()?);
        *g = Some(Conn { writer: stream, reader });
        Ok(())
    }

    fn send(&self, req: &Request) -> Result<Response> {
        self.ensure_conn()?;
        let mut g = self.conn.lock().unwrap();
        let c = g.as_mut().unwrap();
        writeln!(c.writer, "{}", serde_json::to_string(req)?)?;
        c.writer.flush()?;
        let mut line = String::new();
        c.reader.read_line(&mut line)?;
        Ok(serde_json::from_str(&line).context("解析守护进程响应失败")?)
    }
}

impl PlatformBackend for MacBackend {
    fn components_installed(&self) -> bool { install::helper_installed() }

    fn install_components(&self, resource_dir: &Path) -> Result<()> {
        install::install_helper(&resource_dir.join("resources").join("helper").join("fastgithub-gui-helper"))
    }

    fn enable(&self, kernel_dir: &Path) -> Result<()> {
        if !self.components_installed() {
            bail!("后台组件未安装");
        }
        self.ensure_conn()?;
        let resp = self.send(&Request::Enable { kernel_dir: kernel_dir.to_string_lossy().into() })?;
        if !resp.ok { bail!(resp.message); }
        if gitcfg::git_available() {
            let backup = gitcfg::read_backup();
            let p = paths::app_paths();
            std::fs::write(&p.git_backup_file, serde_json::to_vec(&backup)?)?;
            gitcfg::apply(&p.cacert)?;
        }
        Ok(())
    }

    fn disable(&self) -> Result<()> {
        let resp = self.send(&Request::Disable);
        if gitcfg::git_available() {
            let p = paths::app_paths();
            let backup: gitcfg::GitBackup = std::fs::read_to_string(&p.git_backup_file).ok()
                .and_then(|s| serde_json::from_str(&s).ok()).unwrap_or_default();
            gitcfg::restore(&backup)?;
        }
        match resp { Ok(r) if !r.ok => bail!(r.message), Err(e) => return Err(e), _ => Ok(()) }
    }

    fn status(&self) -> Result<String> {
        if !self.components_installed() { return Ok("off".into()); }
        Ok(self.send(&Request::Status)?.state)
    }

    fn uninstall(&self) -> Result<()> {
        if self.components_installed() {
            let _ = self.send(&Request::Uninstall);
            *self.conn.lock().unwrap() = None;
            install::uninstall_helper()?;
        }
        if gitcfg::git_available() { let _ = gitcfg::restore(&gitcfg::GitBackup::default()); }
        Ok(())
    }
}
```

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
use fastgithub_gui_lib::{
    state::{AppState, ToggleAction},
    backend::PlatformBackend,
    backend::macos::MacBackend,
    paths, kernel, gitcfg,
};
use std::sync::{Arc, Mutex};
use tauri::{
    menu::{Menu, MenuItem, PredefinedMenuItem},
    tray::TrayIconBuilder,
    image::Image,
    Manager,
};

struct TrayHandles { status: MenuItem<tauri::Wry>, toggle: MenuItem<tauri::Wry> }

fn set_state(app: &tauri::AppHandle, s: AppState) {
    let label = s.label();
    let on = matches!(s, AppState::On);
    let busy = matches!(s, AppState::Starting | AppState::Stopping);
    {
        let st = app.state::<Arc<Mutex<AppState>>>();
        *st.lock().unwrap() = s;
    }
    if let Some(h) = app.try_state::<TrayHandles>() {
        let _ = h.status.set_text(&label);
        let _ = h.toggle.set_text(if on { "关闭加速" } else { "开启加速" });
        let _ = h.toggle.set_enabled(!busy);
    }
    if let Some(tray) = app.tray_by_id("main") {
        let icon = if on { Image::from_bytes(include_bytes!("../icons/tray-on.png")) }
                   else { Image::from_bytes(include_bytes!("../icons/tray-off.png")) };
        if let Ok(img) = icon { let _ = tray.set_icon(Some(img)); }
    }
}

fn dialog(app: &tauri::AppHandle, msg: &str) {
    let script = format!("display dialog {} buttons {{\"好\"}} default button \"好\"",
        format!("\"{}\"", msg.replace('\\', "\\\\").replace('"', "\\\"")));
    let _ = std::process::Command::new("osascript").arg("-e").arg(script).output();
    let _ = app;
}

fn finish(app: &tauri::AppHandle, r: anyhow::Result<()>, success: AppState) {
    match r {
        Ok(_) => set_state(app, success),
        Err(e) => { let msg = format!("{e:#}"); set_state(app, AppState::Error(msg.clone())); dialog(app, &msg); }
    }
}

fn handle_menu(app: &tauri::AppHandle, id: &str) {
    let backend = app.state::<Arc<MacBackend>>().inner().clone();
    match id {
        "toggle" => {
            let action = app.state::<Arc<Mutex<AppState>>>().lock().unwrap().toggle_target();
            let app2 = app.clone();
            match action {
                Some(ToggleAction::Enable) => {
                    set_state(app, AppState::Starting);
                    std::thread::spawn(move || {
                        let p = paths::app_paths();
                        let r: anyhow::Result<()> = (|| {
                            if !backend.components_installed() {
                                let rd = app2.path().resource_dir()?;
                                backend.install_components(&rd)?;
                            }
                            backend.enable(&p.kernel_dir)
                        })();
                        finish(&app2, r, AppState::On);
                    });
                }
                Some(ToggleAction::Disable) => {
                    set_state(app, AppState::Stopping);
                    std::thread::spawn(move || { let r = backend.disable(); finish(&app2, r, AppState::Off); });
                }
                None => {}
            }
        }
        "reinstall" => {
            let app2 = app.clone();
            std::thread::spawn(move || {
                if let Ok(rd) = app2.path().resource_dir() {
                    if let Err(e) = backend.install_components(&rd) { dialog(&app2, &format!("安装失败：{e:#}")); }
                }
            });
        }
        "uninstall" => {
            let app2 = app.clone();
            std::thread::spawn(move || {
                if let Err(e) = backend.uninstall() { dialog(&app2, &format!("卸载失败：{e:#}")); }
                else { dialog(&app2, "已卸载后台组件并还原设置。应用本体可手动删除。"); }
            });
        }
        "quit" => { let _ = backend.disable(); app.exit(0); }
        _ => {}
    }
}

fn main() -> anyhow::Result<()> {
    let backend = Arc::new(MacBackend::new());
    let app_state = Arc::new(Mutex::new(AppState::Off));
    tauri::Builder::default()
        .plugin(tauri_plugin_single_instance::init(|_app, _args, _cwd| {}))
        .manage(app_state.clone())
        .manage(backend.clone())
        .setup(move |app| {
            #[cfg(target_os = "macos")]
            app.set_activation_policy(tauri::ActivationPolicy::Accessory);

            let p = paths::app_paths();
            let res_kernel = app.path().resource_dir()?.join("resources").join("kernel");
            if !p.kernel_dir.join("fastgithub").exists() {
                kernel::extract_resources(&res_kernel, &p.kernel_dir)?;
            }

            // 启动一致性：若处于关闭态，清理崩溃可能残留的 git 配置
            if backend.status().unwrap_or_else(|_| "off".into()) == "off" && gitcfg::git_available() {
                let backup: gitcfg::GitBackup = std::fs::read_to_string(&p.git_backup_file).ok()
                    .and_then(|s| serde_json::from_str(&s).ok()).unwrap_or_default();
                let _ = gitcfg::restore(&backup);
            }

            let status = MenuItem::with_id(app, "status", "已关闭", false, None::<&str>)?;
            let toggle = MenuItem::with_id(app, "toggle", "开启加速", true, None::<&str>)?;
            let reinstall = MenuItem::with_id(app, "reinstall", "重新安装组件", true, None::<&str>)?;
            let uninstall = MenuItem::with_id(app, "uninstall", "卸载…", true, None::<&str>)?;
            let quit = MenuItem::with_id(app, "quit", "退出", true, None::<&str>)?;
            let version = MenuItem::with_id(app, "version", "FastGithub GUI 0.1.0", false, None::<&str>)?;
            let sep = PredefinedMenuItem::separator(app)?;
            let menu = Menu::with_items(app, &[&status, &toggle, &sep, &reinstall, &uninstall, &quit, &version])?;
            app.manage(TrayHandles { status: status.clone(), toggle: toggle.clone() });

            TrayIconBuilder::with_id("main")
                .icon(Image::from_bytes(include_bytes!("../icons/tray-off.png"))?)
                .icon_as_template(false)
                .tooltip("FastGithub GUI")
                .menu(&menu)
                .show_menu_on_left_click(true)
                .on_menu_event(|app, e| handle_menu(app, e.id.as_ref()))
                .build(app)?;
            Ok(())
        })
        .build(tauri::generate_context!())?
        .run(|_app, event| {
            if let tauri::RunEvent::ExitRequested { api, code, .. } = event {
                if code.is_none() { api.prevent_exit(); }
            }
        });
    Ok(())
}
```
